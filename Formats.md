# Formats

The formats this wiki's owner plays, in priority order (most to least
important). Player and concept takes should be tagged with the format(s)
they apply to when a source specifies it — advice frequently diverges by
format (e.g. a name-brand injury-prone RB can be a dynasty fade but a
perfectly fine best ball punt).
